## 2. Model Input Format & Causal Asymmetry

### 2.1 Prompt Structure
In decoder-only autoregressive architectures like Mistral-7B, the prompt order defines the information flow:

```text
<s> [INST] Answer my questions based on the given context.
---
## Context
Document 1. <passage 1 text>
...
Document 10. <passage 10 text>
---
## Your Task
Answer the following question in a succinct manner. Use a single phrase or a short sentence if possible.
Question: <question text>
Your Answer: [/INST]
```

### 2.3 Mathematical Validity Under Causal Masking
Under Mistral's strictly lower-triangular causal attention mask ($j \le i$):
1. **Passage tokens appear before the query:** Because $j_{\text{query}} > i_{\text{passage}}$, passage tokens cannot attend to query tokens.
2. **Passage hidden states are query-agnostic:** At all layers $0 \dots 31$, the representations of passages $D_1 \dots D_{10}$ are computed with zero query context.
3. **Query tokens contextualize against passages:** Query tokens at positions $2331 \dots 2347$ attend over all preceding context tokens.
4. **Directional Terminology:** Any similarity or attention metric reflects **query-to-passage attention** and contextualization, never the reverse.

## 3. Representation Metric Formulation

For live execution with Mistral-7B, representations are extracted as follows:

1. **Mean-Pooling:** For any semantic span $I(S) = [t_{\text{start}}, t_{\text{end}})$:
   $$\bar{h}_S^{(l)} = \frac{1}{|I(S)|} \sum_{t \in I(S)} h_t^{(l)}$$
2. **L2 Normalization:**
   $$\hat{h}_S^{(l)} = \frac{\bar{h}_S^{(l)}}{\|\bar{h}_S^{(l)}\|_2}$$
3. **Cosine Similarity:**
   $$\text{Sim}(Q, D_i)^{(l)} = \langle \hat{h}_Q^{(l)}, \hat{h}_{D_i}^{(l)} \rangle$$
4. **Evidence vs. Non-Annotated Passage Separation:**
   $$\Delta \text{Sim}^{(l)} = \frac{1}{|E|} \sum_{D_i \in E} \text{Sim}(Q, D_i)^{(l)} - \frac{1}{|NE|} \sum_{D_j \in NE} \text{Sim}(Q, D_j)^{(l)}$$
   where $E$ represents passages matching annotated gold evidence paragraphs, and $NE$ represents non-annotated retrieved passages.
